# Chivas del Rodadero

Programa en Python para llevar el registro diario de pasajeros de las chivas turísticas de la empresa **Chivas del Rodadero** (Santa Marta y El Rodadero) y calcular los indicadores de ocupación.

Trabajo de fin de curso de **Fundamentos de Programación**, Facultad de Ingeniería, Universidad del Magdalena. Alternativa F · Período 2026-II · Entrega: 23-11-2026.

## Cómo ejecutarlo

Requiere Python 3.10 o superior y solo usa la biblioteca estándar.

``bash
git clone https://github.com/Proyecto-de-Programaciion/chivas-del-rodadero.git
cd chivas-del-rodadero
python user_interface.py
``

El menú principal tiene siete opciones: crear chiva, registrar el día siguiente, simular días, ver el informe, ver la mayor y menor ocupación, cargar desde archivos y salir.
